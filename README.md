# ForTUI

This is a little TUI framework written in modern FORTRAN as a little coding challenge. This is 
nothing serious. Just a little play around. The idea mainly stems from libraries in Rust like
`ratatui` or `ncurses`. C interop is fine, really, but I like to keep it clean and Fortran. We will
see where this goes. 

**Disclaimer**: I mainly work on my machine, so I don't care much about other plattforms as long as
I'm not forced to use them. So this library will work on anything supporting `stty` or `/dev/tty`.
Windows doesn't have 'em. The challenge would be fun to do it in a broader consense, too. But since
I'm not using AI to code, I will focus on the necessary parts for me.
